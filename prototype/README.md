# プロトタイプ(実験版)

軽量テキスト防災サイトの技術検証用プロトタイプ。**実運用を意図したものではない**(誤り・欠落があり得るため、この段階のものを公開して避難判断に使ってはならない)。

## 目的

1. 気象庁 防災情報XML(無償Atomフィード)から静的テキストHTMLを生成するパイプラインが成立することの確認
2. 生成ページが数KB級に収まることの確認
3. 128kbps級低速回線での表示時間を、既存の防災サイトと比較する一次実測データの取得(第1次調査の残課題「128kbps実測」への回答)

## 構成

```
generator/generate.py   # フィード取得 → 静的HTML生成(Python標準ライブラリのみ)
site/                   # 生成結果のスナップショット(生成時点の実データ)
measure/measure.mjs     # Playwright + CDPによる128kbps帯域エミュレーション計測
measure/results.md      # 計測結果
```

## 実行方法

```sh
# サイト生成(気象庁フィードを取得して site/ に出力)
python3 generator/generate.py

# 計測(別ターミナルでローカル配信してから)
python3 -m http.server 8123 --directory site
cd measure && npm install && node measure.mjs
```

## プロトタイプとしての限界(設計フェーズで解消すべき点)

- 警報種別の重大度分類が簡易(見出し文字列と種別名の文字列マッチ)。本実装では気象庁の種別コード表に基づく分類が必要
- 津波情報の扱いが最小限(直近電文の有無の表示のみ)
- 気象警報・注意報(VPWW54)と震源・震度(VXSE53)のみ対応。特別警報の発表状況・噴火・台風情報等は未対応
- フィード停止検知・鮮度劣化表示は未実装(設計要件には含める)
- 「解除」電文が最新の場合の表示検証が不十分
- エラー時のリトライ・フォールバックなし

## データ出典と利用条件

- 出典: 気象庁ホームページ 防災情報XMLフォーマット形式電文(PULL型)
  - フィード: https://www.data.jma.go.jp/developer/xml/feed/
  - 利用規約: https://www.jma.go.jp/jma/kishou/info/coment.html
- フィードは無償・ベストエフォート提供(リアルタイム性のサポートなし、急な配信停止があり得る)
