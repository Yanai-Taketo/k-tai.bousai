# k-tai.bousai — 文字中心・軽量防災サイト構想

通信環境が悪い場所や輻輳した環境でも読める、旧来のケータイサイトのような**文字中心の軽量防災サイト**をつくるプロジェクト。

地図タイルや大量のJavaScriptに依存する近年の防災サイトは、災害時のアクセス集中・低速回線・応急復旧された細い回線の下で実用にならないことがある。本プロジェクトは、数KB〜数十KB級のテキストページで防災情報を届けることの実現性を検証し、設計・制作・テスト・公開までを目指す。

生命に関わる情報を扱うため、**一次情報(政府機関・気象庁・通信キャリア等の公式発表)の確認を必須**とする方針で進めている。

### 調査結論の要旨

- **存在意義**: 供給側の根拠は強い(条件付きで存在意義あり)。災害時・アクセス集中時に防災系サイトが閲覧困難になり、政府・自治体自身が「テキスト中心への軽量化」で対処してきた事実は一次資料で確認できた。一方、需要側(災害時に住民が実際にWebで情報を取りに行くか、無名サイトに到達できるか)の裏付けは未収集。
- **実現性**: 技術的・法的には成立する。気象庁の警報・注意報・地震津波情報の「そのまま転載」は予報業務許可不要で、無償の防災情報XML Atomフィードから機械可読で取得できる。ただし旧3Gケータイ向けサイトの文字どおりの再現は不可能(3G全停波・TLS要件)で、現実的な対象は「低速・輻輳回線下のスマホ」と「現行4Gケータイ」。
- **最大の制約**: 避難指示・避難所開設情報を個人が機械可読で入手する公式経路が現状存在しない(Lアラートは法人限定・新規受付停止中、2026年12月に総務省移管後に再開予定)。
- **限界の明示**: 軽量化が効くのはサーバ輻輳・低速回線であり、基地局停波・圏外には効かない。本サイトはエリアメールや放送の代替ではなく補完手段。

次フェーズ(要件定義・設計)は、報告書「10. 依頼者に相談すべき論点」の合意後に着手する。
