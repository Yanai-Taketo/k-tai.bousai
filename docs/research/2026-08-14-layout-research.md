# 他の気象防災サービスのレイアウト調査と本サイトへの適用方針

依頼者からの「他の気象防災サービスを参考に、どのような配置が見やすいのかエージェントで検討してほしい。警報・注意報はテーブルで整理できないか。地震・津波・台風のサンプルも欲しい」(決定#18・#19)を受けた調査記録。7方面の並列調査(気象庁・Yahoo!天気・災害・NHK・tenki.jp/ウェザーニュース・軽量デザイン先行事例・表組みアクセシビリティ・電文仕様)と統合提案を実施した。各調査は実HTML・実電文・公式資料の一次確認に基づく(推測は原文中で明示)。

## 1. 調査対象と主要な発見

### 気象庁 (www.jma.go.jp/bosai/)

- トップは常に「いま発表中の危険情報ダイジェスト(パネル)」が最上部固定。平常時も枠を消さない。
- 警報・注意報ページは「サマリが先・市町村別マトリクスは最後」。マトリクスは行=市町村、**列=発表中の現象のみ**(全県ゼロなら表を出さず1行文)。セルは1〜4字略記(注/警/特/レベルＮ)+背景色。
- レベル色(実CSSで確認): 注意報#F2E700黄・警報#FF2800赤・危険警報#AA00AA紫・特別警報#0C000C黒。
- 各表の直下に必ず「〜時〜分更新」行。見出し文(headline)は表の外に文章で掲出。

### Yahoo!天気・災害(サーバレンダリングで全表を実見)

- 警報は階層で集約度を変える: 全国=県ごとに最高レベル1個のチップ、**府県=行=市区町村・警報は1セルに名称列挙(現象を列にしない・列数固定)**、現象×時間マトリクスは市区町村単位ページ限定。
- 「発表なし」を空欄でなく文字で明記。表の下に警戒レベル5〜2と行動指針の対応表を共通部品化。
- 地震詳細: ラベル|値の縦2列諸元表→震度別(降順)→県→市町村名列挙。津波・台風は平時も凡例+行動文+履歴で常設。

### NHKニュース防災 / NHK NEWS WEB

- 「平時=天気が先/有事=警報が先」の二面構成。発災時はトップ最上部に緊急帯を1本注入。
- 気象防災速報は表でなく1行定型「千葉 御宿町にレベル4土砂災害危険警報(19:03)」(自動生成見出しの実見)。
- ハザード別に恒常URLを持ち、イベントが無くても「発表なし」+備え解説を常設。

### tenki.jp / ウェザーニュース

- 両社ともモバイルで市町村×現象マトリクスを使わない。tenki.jp府県=行=市区町村・セルに現象チップ列挙。WN=市町村行に「レベル4土砂災害」形式のレベル数字入りチップ(新体系対応済み。tenki.jpは未対応と明記中)。
- 全ページ共通の頭部: タイトル+「○日○時現在」→概況文1〜2文→詳細表。
- 地震ページは津波有無の一文を最上部固定(tenki.jp lite実装)。

### 軽量・文字中心の先行事例(NERV防災・旧気象庁・NHKテキスト版・Yahoo!3.11)

- NERVはスクリーンリーダー時に地図を丸ごと省略しても成立する設計。文字サイトは「その省略後の形」を常時形にできる。
- 旧気象庁の非JS向け23列固定マトリクスは狭い画面で破綻する反面教師。現行モバイル全社が「発表中のみに縮約」方式。
- NHKテキスト版(文字ニュース)は提供終了済みで、低速回線・支援技術向け文字防災サイトは現状空白領域。

### 表組み・アクセシビリティの技術定石

- 表は2次元比較のときだけ使う(GOV.UK/W3C)。1次元の列挙はリスト・段落の方が軽量で折返しに強い。
- 最小レスポンシブ表: `div role="region" aria-labelledby="(captionのid)" tabindex="0"`+`overflow-x:auto`+`:focus{outline}`のみ。CSSのdisplay変更によるカード化はセマンティクス破壊で禁止。
- **コントラスト実測**: 赤#FF2800に白文字は3.78:1でWCAG AA不合格(黒文字なら5.56:1で合格)。黄#F2E700黒文字16.2:1、紫#AA00AA白文字6.38:1、黒#0C000C白文字20.6:1。「背景チップ+固定文字色」はライト/ダーク両モード共通で成立するが、警報色を文字色に使うとダークモードで紫が2.93:1に落ちる。
- 気象庁「配色に関する設定指針」(令和2年7月)の公式RGBをそのまま使うと利用者の色連想と一致する。

### 電文仕様からの確認(実電文で裏取り)

- 地震: VXSE53は定型見出し文+5項目(発生時刻・震央・深さ・M・最大震度)+震度降順の階層リスト+固定付加文(津波の有無、コード0215/0217)で完結。gzip実測3.0KB(観測点込み)→市町村単位要約で予算内。
- 津波: VTSE41は行=津波予報区の固定形[予報区/種別/予想の最大の高さ/到達予想]。到達予想は時刻または状況文言(「津波到達中と推測」)。平時定型文「現在、大津波警報・津波警報・津波注意報を発表している沿岸はありません」。
- 台風: VPTW60-65。公式の文章項目順=中心位置→進行方向と速さ→中心気圧→最大風速→最大瞬間風速→暴風域→強風域。予報円は「中心位置+半径km」の数値2つで文字表現可能。速度「ゆっくり」等の文字conditionは正規の値。

## 2. 本サイトへの適用方針(モック案C)

- **トップ**: 決定#17(案B)を微調整。最上部「いま発表中の重要情報」を津波→地震→気象警報→台風の深刻度順の各1行にし、平時も「発表なし」を能動的に明記。地震・津波・台風の恒常ページリンクを常設。県リンクには最高レベルの1字バッジ(特/危/警/注)+チップを前置、発表なし県は素リンク。
- **府県ページ**: (1)タイトル+時刻 (2)最大レベル帯+概況文 (3)警報・注意報表——**一次細分区域ごとに表を分割(caption)、行=発表区域(市町村等をまとめた地域)、列は2本固定[発表区域|発表中の警報・注意報]、セルに正式名称の色チップをレベル降順で列挙、「発表なし」明記**。全県ゼロなら表を出さず1行文(平時は天気が実質先頭に上がる=NHKの二面性の静的等価) (4)気象防災速報(1行定型の時系列) (5)天気予報(今日明日+降水確率4区分ミニ表+週間表) (6)警戒レベルと行動の対応。
- **地震**: 津波有無の一文を最上部固定→定型見出し文→縦2列諸元表→震度降順の階層リスト(表を使わない)→直近10件リスト。
- **津波**: 現況帯→行動文→予報区の4列固定表→原因地震の諸元→種類凡例。平時は公式定型文1行+凡例のみ。
- **台風**(スコープ判断待ち): 概況文(公式項目順)→実況の縦2列表→予報の時刻別表(予報円は半径kmの数値)→平時は「現在、台風は発生していません。」1行。

### やってはいけないこと(調査帰結)

1. 市町村×現象の全列固定マトリクス(旧気象庁23列型)を府県ページで使う
2. 色のみでレベルを区別する(チップに必ず名称テキスト)
3. 赤#FF2800の背景に白文字(AA不合格。黒文字にする)
4. 警報色を「文字色」として使う(ダークモードで破綻)
5. 「発表なし」「津波の心配なし」を空欄・非表示で表現する
6. CSSのdisplay変更で表をカード化する
7. 発表中でない現象のために列・行を確保する
8. 表・ページの発表/更新時刻を省略する
9. レイアウト目的でtableを使う(県リンク一覧・速報はリスト/段落)

モック実測(gzip): トップ1.9KB/府県2.3KB/地震1.7KB/津波2.0KB/台風2.0KB——いずれも予算(5/8/6/3KB)に大きな余裕。モックは `docs/mockups/` に保存。
