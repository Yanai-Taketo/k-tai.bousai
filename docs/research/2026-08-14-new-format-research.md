# 「新たな防災気象情報」(2026年5月29日運用開始)電文仕様 調査記録

- 作成日: 2026-08-14
- 位置づけ: 設計書§8の根拠となる電文仕様調査。すべて一次資料(気象庁公式ページ・配信資料に関する技術情報第634号・公式解説資料・実フィード/実電文の採取)で確認済み。
- 実フィード採取: 2026-08-14に extra.xml / extra_l.xml(長期、10,491件)/ regular.xml をcurlで取得し、電文コード別の配信実態を集計・実電文を目視確認した。

## 要旨

1. 新体系の**運用開始日は令和8年(2026年)5月29日(金)**。前日5月28日(木)13:50以降、新名称での発表に切替(12:30頃に発表中の警報等を一旦全解除→13:50頃再発表)[^s1]。
2. 対象は**河川氾濫・大雨・土砂災害・高潮の4災害**。警戒レベル5=特別警報、**レベル4=危険警報(新設区分)**、レベル3=警報、レベル2=注意報、レベル1=早期注意情報に統一し、**名称自体に「レベルN」を付す**(例: レベル４大雨危険警報)[^s2]。
3. 洪水警報・洪水注意報(市町村ごと)は**運用終了**(大雨に一体化)。土砂災害警戒情報→**レベル４土砂災害危険警報**。記録的短時間大雨情報・顕著な大雨に関する気象情報→**気象防災速報**に統合。津波・地震・火山、暴風/波浪/大雪等は**変更なし**[^s2]。
4. XML電文は「配信資料に関する技術情報**第634号**」が正典。新設**VPWW55〜61**(災害種別ごとに分割)、VPWP50(時系列)、VPWS50(集約通報)、VPFD61、VPBS50、VPZJ51/VPCJ51/VPFJ51等。**旧電文(VPWW53/54, VXWW50, VPOA50, VPFJ50, VPFD60等)は「運用開始後2年程度」併配信**(移行措置。終了日は未発表)[^s3]。
5. 2026-08-14時点の実フィードで**新旧両電文の併流を実測確認**。府県天気予報(VPFD51)・週間天気予報(VPFW50)は**今回の改定で変更なし**。

## 1. 新名称体系と警戒レベル対応(公式概要資料 p.4 原文どおり)[^s2]

| 警戒レベル | 河川氾濫 | 大雨 | 土砂災害 | 高潮 |
|---|---|---|---|---|
| **5相当** | レベル５氾濫特別警報 | レベル５大雨特別警報 | レベル５土砂災害特別警報 | レベル５高潮特別警報 |
| **4相当** | レベル４氾濫危険警報 | レベル４大雨危険警報 | レベル４土砂災害危険警報 | レベル４高潮危険警報 |
| **3相当** | レベル３氾濫警報 | レベル３大雨警報 | レベル３土砂災害警報 | レベル３高潮警報 |
| **2** | レベル２氾濫注意報 | レベル２大雨注意報 | レベル２土砂災害注意報 | レベル２高潮注意報 |
| **1** | 早期注意情報(4災害共通) | | | |

- 「危険警報」はレベル4相当の**新設区分**。「気象警報・注意報」の公式定義は「気象特別警報、気象危険警報、気象警報及び気象注意報」となった。
- 氾濫系(指定河川洪水予報)は洪水予報河川(約400河川)のみ・河川ごと。**気象台による市町村ごとの洪水警報・注意報は廃止**(内水氾濫等は大雨に関する情報で扱う)。
- レベル５高潮特別警報は「氾濫が発生または切迫している場合」に発表(**旧・高潮特別警報とは意味が変わる**——旧はレベル4相当)。
- レベル非対応(名称変更なし): 暴風・波浪・大雪・暴風雪の特別警報/警報、強風・波浪・大雪・風雪・濃霧・雷・乾燥・なだれ・着氷・着雪・霜・低温・融雪の注意報。
- **津波・地震・火山は今回の体系整理の対象外**(電文も変更なし)。

## 3. XML電文の変更(技術情報第634号)[^s3]

### 新設電文(2026-08-14の実フィードで配信を確認済み。※印は未観測)

| コード | 情報名 | 備考 |
|---|---|---|
| VPWW55 | 気象警報・注意報(Ｒ０６)(大雨) | VPWW54+VXWW50+VPFD60を再構成 |
| VPWW56 | 同(土砂) | 土砂災害警戒情報と統合 |
| VPWW57 | 同(高潮) | |
| VPWW58 | 同(暴風)※暴風雪含む | |
| VPWW59 | 同(波浪) | |
| VPWW60 | 同(大雪) | ※夏期のため実電文未観測 |
| VPWW61 | 同(その他注意報) | 雷・融雪・濃霧・乾燥・なだれ・低温・霜・着氷・着雪等 |
| VPFD61 | 早期注意情報(明後日まで) | |
| VPWP50 | 気象警報・注意報時系列情報(Ｒ０６) | **切替予告(NextKinds)はここに集約**(VPWW55〜61では提供しない) |
| VPWS50 | 気象警報・注意報(Ｒ０６)(集約通報) | 全要素の発表状況を高頻度で定常通報 |
| VPBS50 | 府県気象防災速報 | VPOA50+VPFJ50の極端現象速報を統合 |
| VPBS51 | 府県気象防災速報(潮位) | ※提供開始時期未定 |
| VPZJ51/VPCJ51/VPFJ51 | 全般/地方/府県気象解説情報 | 旧 気象情報の再編 |
| VXSUii(50〜59) | 水位周知河川に関する情報 | ※提供開始時期未定 |

指定河川洪水予報は**VXKOii(50〜89)の従来電文を当面継続**し、電文内の種類名のみ新名称に更新。

### 警戒レベル等対応コード(公式解説資料 別表3。実電文で裏どり済み)

- 大雨: 33=レベル５大雨特別警報 / **43=レベル４大雨危険警報(新)** / 03=レベル３大雨警報 / 10=レベル２大雨注意報
- 土砂: **39=レベル５土砂災害特別警報(新)** / **49=レベル４土砂災害危険警報(新)** / **09=レベル３土砂災害警報(新)** / **29=レベル２土砂災害注意報(新)**
- 高潮: 38=レベル５高潮特別警報 / **48=レベル４高潮危険警報(新)** / 08=レベル３高潮警報 / 19=レベル２高潮注意報
- 変更なし: 02/05/06/07(警報)、32/35/36/37(特別警報)、12〜27(注意報)、00=解除
- 04=洪水警報/18=洪水注意報はコード残置(経過措置電文用。新体系では発表されない)。42/45/46/47は将来予約領域
- VXKO/VXSU系: 51,53=レベル５氾濫特別警報系 / 40,41=レベル４氾濫危険警報 / 30,31=レベル３氾濫警報 / 20,21,22=レベル２氾濫注意報系 / 10=解除
- 新電文はInfoKindVersion **1.5_0**(実電文で確認)

### 併配信(経過措置)と廃止

- **併配信(新電文運用開始後「2年程度」=2028年5月頃まで。終了日未発表)**: VPWW53、VPWW54、VPFD60、VPNO50、**VXWW50**(Head/Titleは「○○県レベル４土砂災害危険警報」に変更済み)、VPOA50、VPZJ50/VPCJ50/VPFJ50、VMCJ50/51/52 ほか。VPWW54のNextKinds切替予告は運用終了。
- **終了済み**: VPTI50/51/52(全般台風情報)、VPRN50(大雨危険度通知)ほか。
- **内容変更して継続**: VPHW50/51(中身は「気象防災速報(竜巻注意)/(竜巻目撃)」)、VPFW60(中身は「早期注意情報(明々後日以降)」)。

## 4. 実フィード採取結果(2026-08-14、extra_l.xml=収録2026-08-07〜08-14・10,491件)

主要な電文コード別件数: VPWW54=3,222 / VPWW53=3,222(いずれも経過措置)/ VPWW55=843 / VPWW56=684 / VPWW61=500 / VPFJ50=443・VPFJ51=433(同内容併流)/ VPWW59=203 / VPWW58=175 / VXWW50=93(**フィードtitleは「土砂災害警戒情報」のまま、中身は「レベル４土砂災害危険警報」**)/ VPBS50=43 / VPOA50=33 / VPHW50=22・VPHW51=22 / VXKO系=11 / VPWW57=9。

## 5. 府県天気予報・週間天気予報

- **今回の改定で変更なし**(第634号の新設・変更・廃止・経過措置のいずれのリストにも含まれない)。
- 現行はVPFD51「府県天気予報(Ｒ１)」・VPFW50「府県週間天気予報」・VPFG50「府県天気概況」(regular.xmlで実測確認)。仕様書は令和2年10月1日版のまま[^s4]。
- 紛らわしい近縁コード: VPFD60(警報級の可能性(明日まで)=経過措置)/VPFD61(早期注意情報(明後日まで)=新設)/VPFW60(中身は早期注意情報(明々後日以降))は天気予報電文ではない。
